# v1.6.3

## English

User cabinet **reloads the menu** from the API on each screen (admin edits no longer stick in memory). Admin slug field no longer uses a fake `faq` placeholder; it lowercases input and has a **New tab** reset so HTML5 validation cannot block a real FAQ page.

```bash
bash remnawave-manager.sh self-update
```
