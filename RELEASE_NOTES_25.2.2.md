Interactive menu with a description of every function. UI language: English or Russian (`--lang en|ru`, menu item 22). GitHub has two READMEs: [English](README.md) and [Русский](README.ru.md).

```bash
curl -fL --retry 5 --retry-all-errors \
  https://cdn.jsdelivr.net/gh/booarkz-cpu/remnawave-manager@v25.2.2-prod/remnawave-manager.sh \
  -o remnawave-manager.sh
sudo bash remnawave-manager.sh
```

Language: `sudo bash remnawave-manager.sh --lang en` or `--lang ru`.
