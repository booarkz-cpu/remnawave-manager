### POST /users

Source: https://github.com/remnawave/backend/blob/main/_autodocs/02-endpoints.md

Creates a new user in the system with specified configuration.

```APIDOC
## POST /users

### Description
Create a new user.

### Method
POST

### Endpoint
/users

### Request Body
- **username** (string) - Required - Username (3-36 chars, alphanumeric + `-_`)
- **status** (enum) - Optional - User status: ACTIVE, DISABLED, EXPIRED, LIMITED
- **shortUuid** (string) - Optional - Short UUID identifier
- **trojanPassword** (string) - Optional - Trojan protocol password (8-32 chars)
- **vlessUuid** (string) - Optional - VLESS protocol UUID
```

```APIDOC
## GET /users/:userId/accessible-nodes
```
